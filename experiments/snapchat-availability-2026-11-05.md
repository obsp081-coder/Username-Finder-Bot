# تحقيق جدوى فحص أسماء Snapchat

التاريخ: 2026-11-05. حالة التجربة: **BLOCKED**. قرار الدمج: **NO-GO** بالأدلة الحالية؛ لم يثبت استحالة وجود طريقة أخرى.

## النطاق والنتيجة

فُحص عقد `Verifier` الحالي دون تعديله. لم تُعدّل الواجهة أو المحرك أو قاعدة البيانات أو القوالب أو السجل، ولم يُفعّل الموفر الحقيقي. جرى فحص المصادر عن بُعد دون تنزيل مشروع خارجي وتشغيله، أو تثبيت حزم، أو إنشاء حسابات، أو استخراج رموز، أو استخدام ملفات ارتباط/وكلاء/تجاوزات. لم يُنشأ فاحص يوحي بنجاح غير مثبت؛ بقيت التجربة بحثًا وطلب نفاذ وحيدًا، مع دليل مستقل في `snapchat-access-2026-11-05.json`.

### معنى protobuf التاريخي ومتطلبات المصادقة

تعريف الرسائل المنشور يعود إلى تغيير ملف بتاريخ 2025-02-15، ومستودع Android المفكك يعود إلى 2024؛ تاريخ رفع الملف لا يثبت إصدار البروتوكول أو صلاحيته الحالية. حقول طلب الفحص تشمل الاسم وإصدار الطلب ومعرّفات سياق العميل. رد الفحص يحتوي `state` و`suggestionsArray` و`errorMessage`.

| الحالة التاريخية | التفسير الممكن إذا ثبت عقد الرد الحديث مستقلًا |
|---|---|
| `USERNAME_AVAILABLE=1` | إشارة صريحة محتملة إلى `Available`؛ لا تُعتمد هنا دون نفاذ حديث ومقارنة رسمية إيجابية وسلبية. |
| `TAKEN=8` | إشارة تاريخية إلى `Taken` ضمن ذلك العقد، وليست نتيجة حصلنا عليها. |
| `TOO_SHORT=2` إلى `INVALID_SEPARATED=7` | حالات رفض صيغة محددة؛ قد تدعم `Invalid` بعد التحقق من العقد. |
| `DELETED=9` | حالة حذف تاريخية؛ لا تعني التوفر، ولا تُحوّل تلقائيًا إلى `Reserved` أو `Taken`. |
| `SAME_AS_PASSWORD=10` | رفض متعلق بالسياق، ولا يثبت أن الاسم محجوز أو مستخدم. |
| `STATE_UNSET=0`، `ERR_GENERIC_FAILURE=11`، `ERR_THROTTLED=12` | `Unknown`؛ التقييد يستلزم إيقاف التجربة دون إعادة محاولة. |

نقطة مهمة: [منشئ طلب CheckUsername التاريخي، case 2](https://github.com/meltingscales/com.snapchat.android/blob/d19c1ea7299c27a3127fc26649389feb0d3913d9/jadx/sources/defpackage/C19797cA9.java) يضبط خيار المصادقة إلى false. تتبّع [الـbuilder](https://github.com/meltingscales/com.snapchat.android/blob/d19c1ea7299c27a3127fc26649389feb0d3913d9/jadx/sources/defpackage/C48971v9a.java) و[CallOptions](https://github.com/meltingscales/com.snapchat.android/blob/d19c1ea7299c27a3127fc26649389feb0d3913d9/jadx/sources/com/snapchat/client/grpc/CallOptions.java) يبين أنه `mRequireAuth`. لذلك **لا ندّعي أن تسجيل دخول الحساب كان مطلوبًا تاريخيًا**. وفي المقابل، يمر النقل عبر [UnifiedGrpcService الأصلي](https://github.com/meltingscales/com.snapchat.android/blob/d19c1ea7299c27a3127fc26649389feb0d3913d9/jadx/sources/com/snapchat/client/grpc/UnifiedGrpcService.java)؛ غياب تسجيل الدخول لا يثبت غياب سياق العميل أو قيود النفاذ الحالية. المتطلبات الحالية غير متحققة، وليست معلومة افتراضًا.

وللمقارنة، [Creator Discovery الرسمي](https://developers.snap.com/marketing-api/Public-Profile-API/CreatorDiscovery) يعيد بيانات ملفات عامة ويعرض استخدام Bearer token؛ ليس فاحص قابلية حجز أسماء. لا يعني وصف بعض المسارات بأنها Public أنها تعمل دون مصادقة التطبيق.
